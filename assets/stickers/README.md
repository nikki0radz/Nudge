## Shared prompt

Use case: stylized-concept. Asset type: one small transparent PNG sticker for the Nudge reminder app. Use the supplied owl ONLY as a STYLE REFERENCE, not as the subject. Match its dreamy, soft, lightly hand-painted pastel illustration: creamy highlights, rounded chubby silhouettes, muted plum-brown outlines, subtle paper-like colour shading, pale pink/lilac/mint/butter colours. Primary subject: SUBJECT. Exactly one isolated sticker composition centred on a truly transparent background, no extra owl, no character faces. Thick enough rounded outlines and simple large shapes to remain identifiable when rendered at 24–32px. Fills should be clear at tiny sizes, no fussy detail, no cast shadow outside the shape, no sticker white backing, no halo, no border rectangle, no labels, no writing, no watermark. Fill about 80% of the square canvas. Output a crisp PNG with alpha. Aim for 512x512 composition.
